# 桌面农场

Windows 11 x64 本地像素风放置游戏，当前版本 0.8.11。使用 Godot 4.7.2、GDScript 和 C/Win32 GDExtension。三场景的背景、作物、动物和农夫动作使用原创像素素材，中文使用系统字体。

## 试玩

双击 `dist/DesktopFarm-v0.8.11/DesktopFarm.exe`，保持同目录的 `.pck` 和 DLL 文件。无需安装 Godot、Python 或编译器。「种子商店」按数量购买入库并选择默认自动订购。点击或框选耕地后，可以从底栏点「选择种子」。也可先在「种子库」选品种，再到农田选地并提交。当前作物完成本轮后换种，取消安排释放预留种子。整个可用库为空才自动订购，其他库存按固定品种顺序继续播种。

种子商店供应 48 种种子，分为 24 级，每级两种。随等级提高，种价、首熟时间、售价和解锁费逐级上涨。1 级防风草和胡萝卜每枚 20 金币，首熟 12 分钟，收获售 35 金币。24 级远古果实和宝石甜莓各需 280,000 金币解锁，每枚 9,600 金币，首熟 11 小时，收获售 14,500 金币。通用混合种子显示平均售价。春夏秋冬种包和混合花卉种包已下架，旧库存可继续种完。旧档中的当前批次、图鉴和库存保留，若默认订购品种已下架，会改为防风草。

默认展开420逻辑像素，可切换紧凑240或收起工具栏。农场、牧场和鱼塘分开呈现；动物按真实坐标走出棚舍、觅食、进食，点击互动有成长/产出加成及持久化冷却。鱼首次捕获自动消耗登记，此后直接自动出售，全程不弹结果确认；鱼塘入口可升级渔网与容量，最高5秒冷却、36条容量。

拖动工具栏左端 `≡` 移动农场，拖动右端 `↗` 改变宽高，收起时可调整工具栏宽度。尺寸和位置随存档保存，设置中可恢复默认布局。

每块地独立管理，初始24、最多96块；建设中每次开垦一块。设置可调农夫速度16～48像素/秒，默认32；按实际距离行走，到达后才开始2秒动作。所有游戏窗口遵循普通 Windows 前后顺序，点击其他应用后该应用优先显示。

开垦费用按已开地块数递增，从900金币起，最后一块需692,000金币。招聘和储粮升级也按进度提高费用。加载旧档后，下一笔购买按当前价格和已有进度计算。

点击未开垦地块会在底栏显示下一块的价格，并高亮实际将要开垦的地块。「经营 → 建设扩展」负责开垦购买并显示金币缺口。点空白场景可取消地块选择和开垦提示。

农田达到 28、36、48、64 块时会自动摆上四件不同装饰。在「经营 → 农场装饰」可以换位置、收起或在场景里查看，摆法会自动保存。

农场本岗农夫空闲一段时间后，会轮流巡田、照料摆出的花箱、在小屋旁歇脚或去水井旁打水。新的农活和支援任务优先。

托盘菜单和 `Ctrl+Alt+F` 可显示/隐藏游戏，同显示器前台全屏应用会暂时隐藏全部游戏窗口；后台生产继续。快捷键占用时显示明确提示，可继续使用托盘。仅收起场景时工具栏仍可经营。

窄屏下商店快捷按钮会收进经营首页，托盘也能直接打开两个商店。

当前玩法见[试玩说明](docs/play-guide.txt)。三场景和牧场的设计及历史实测见 [0.8.1 开发规格](docs/development-spec-v0.8.1.md)、[验收记录](docs/validation-v0.8.1.md)及[性能报告](docs/release-performance-v0.8.1.md)。美术来源与生成要求见[素材提示词](assets/pixel/v0.8.1/generation-prompts.md)。

Windows 便携包为 `dist/DesktopFarm-v0.8.11-win64.zip`，完整解压后启动程序。包中附玩法说明、开发文档和历史验收记录。启动前先正常退出旧版游戏。首次载入有效 v1/v2 旧档会验证并创建不可覆盖的版本备份，再迁移为 v3，保留金币、库存、任务领用及生产进度。

## 源码运行与构建

首次准备：

```powershell
./scripts/setup_toolchain.ps1
./native/build.ps1
./scripts/run.ps1
```

工具只下载到 `.tools/`，不安装到系统。首次准备需要网络；准备脚本固定使用已验证的 Godot 4.7.2 与 Zig 0.16.0，本机工具路径和校验值写入 `.tools/toolchain.json`。该文件不进入 Git，新电脑重新运行准备脚本。

```powershell
./scripts/test.ps1
./scripts/run.ps1 -Editor
./scripts/build.ps1
```

只更新随包说明、保留已经测量过的EXE/PCK/DLL时，可执行 `./scripts/build.ps1 -PackageOnly`；该参数不会编译源码变化。

Windows 导出需要 `.tools/export-templates/` 中与引擎版本一致的官方模板。安装 Python 3 后，在项目根目录执行一次：

```powershell
python ./scripts/download_windows_templates.py
```

该脚本从官方模板压缩包通过 HTTP Range 只提取 Windows x64 文件，逐文件校验 ZIP CRC 并保存下载收据。完整压缩包没有下载，收据中的整个包 SHA256 不作为已验证结果。发布打包使用真正的导出模板。

配置核验：用 Python 执行 `tests/validate_config.py`。原始数值导出脚本 `scripts/export_config.py` 读取已纳入 Git 的 `data/source/workbook-v0.5.json`，玩法运行不依赖原 Excel 或 Word。逻辑测试覆盖全部内容 ID 及满规模存档恢复；图形和原生验证的实际结果单列。

Windows 下可运行 `./native/tests/test_pond_toolbar.ps1`，用隔离窗口和真实鼠标事件检查连续捕鱼后的场景切换。

## 版本维护

源码、设计文档、数值来源和测试纳入 Git；工具、缓存、截图及 `dist/` 试玩包由本机构建生成。提交与远端同步步骤见 [Git 维护说明](docs/git-workflow.md)。

## 存档

正式试玩保存于Windows用户目录的Godot `app_userdata/桌面农场/desktop-farm-save.json`。设置可打开实际目录。30秒自动保存，经营操作立即保存；写入失败撤回操作。退出与休眠暂停，没有离线收益。损坏主档尝试完整.bak，两份均坏时暂停并保留文件。迁移备份version-v1/v2不可覆盖；迁移写入失败停止启动。旧版无法读v3，回退需全部游戏退出后使用对应原版备份。测试及录制使用独立test-data存档，不使用正式玩家文件。

原始需求、数值来源及已确认变化记录在 `docs/requirements-review-v0.5.md`。源码目录 `.review/`、`.tools/`、测试、截图及原始文件不随试玩包发布。

# v0.6.1 试玩反馈修复

日期：2026-10-01。针对用户实际试玩截图中的空白窗口、商店入口不清晰和游戏遮挡其他应用三个问题。本版沿用v0.6存档，未改成熟时间、售价、保护额、库存或动物退款规则。

## 问题与处理

1. **左上角760×500米白空窗。** 来源是提前显示的经营Window：创建时没有隐藏，内容只在进入面板时生成。现在加入场景树前设为隐藏；内容和位置设置完成后才显示。关闭/Esc会隐藏并清空当前面板标记。原测试仅截取农场视口，未覆盖独立操作系统窗口，所以漏检启动空窗；现已补启动状态与原生窗口回归。
2. **商店入口。** 原有动物买卖在经营→动物市场，作物解锁/选择在经营→区域作物。新版工具栏直接显示种子商店和动物商店，并用清晰的经营导航窗口替代下拉入口。种子面板显示单价、库存和区域选择，说明播种时先用库存、用完自动购种；未擅自增加手动囤种经济规则。动物面板继续支持购买和按标准价50%出售。
3. **永久置顶遮挡工作。** v0.6在项目、host默认值、存档和经营窗多处启用置顶。现在场景、工具栏、经营窗都采用普通Windows Z顺序；点击其他应用后，该应用优先显示。旧存档topmost=true被忽略并随正常保存更新。重复显示已可见窗口、切换输入和后台布局更新不会主动把游戏抬到其他应用前面。经营窗只在用户主动进入时获得焦点。

## 验证

- 核心生产/存档313条断言通过；控制器/面板/输入24条断言通过，增加启动隐藏、普通层级、商店直达和经营导航检查。
- 源码真实OpenGL测试输出 `UI_STARTUP_WINDOW_OK`、`UI_PANELS_OK`、`UI_COLLAPSED_MENU_OK`、`UI_SHOPS_AND_CLOSE_OK`。通过两个工具栏按钮的实际pressed连接进入商店，检查经营窗非置顶，并验证Esc隐藏原生窗口。
- 新导出的独立Windows Release程序从自身目录启动，不传源码路径，退出码0、日志无脚本错误，以上四项检查全部通过。测试截图为 `evidence/release-hotfix-farm*.png`，发布DLL哈希与新编译的原生模块一致。
- 真实跨进程前后台测试 `HOST_WINDOW_PRIORITY_PASS`：三个Godot HWND（场景/工具栏/经营窗）被另一个进程的点击前台窗口覆盖；随后反复应用旧置顶参数、切换输入、移动/刷新布局仍未反超。单独原生降级测试 `PRIORITY_PASS`通过。
- 穿透→互动→穿透跨进程输入回归、收起继续时钟、根视口隐藏后的工具栏真实像素变化、合成休眠消息的同步保存回调全部通过。测试命令与原始验证说明见源码 `native/README.md`。

发布入口为 `dist/DesktopFarm-v0.6.1/DesktopFarm.exe`；便携包 `dist/DesktopFarm-v0.6.1-win64.zip`。测试存档独立于玩家存档。正式休眠、多DPI和长期性能的未测边界沿用原验收报告，v0.6性能报告的文件哈希仅对应历史被测包。

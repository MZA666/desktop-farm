# v0.7.0 实际发布性能

日期：2026-10-01T18:42:07+08:00。测量最终带原创像素图集、静态栅格缓存、牧场分组绘制的独立Windows Release EXE，正常同目录PCK入口，未使用Godot编辑器、--path或--script替代玩法入口。

## 结论

农场、鱼塘、省电、收起的平均CPU低于2%；满规模牧场为2.029%，略超过目标。全部模式的峰值工作集仍超过200MB，最高274.76MB；峰值私有内存最高211.06MB。因此本轮完成了性能优化和有效实测，尚未通过全部性能目标。保留峰值，不以Windows工作集清空、自然释放后的低值或调整采样窗口冒充达标。

## 优化过程

- 原始1254px图集运行时读回转换的30秒样本峰值最大290.10MB；改为离线最近邻转换后，仅加载256×256及3张128×128小图集。
- 仅离线转换版的60秒样本为农场2.122%、牧场2.326%，最大工作集259.72MB。
- 加入静态栅格缓存后，农场60秒样本降至1.682%，牧场仍为2.295%。缓存纹理增加了渲染目标内存，不能宣称只降低CPU便同时降低内存。
- 牧场阴影、图集动物和状态标记分组后，最终牧场主场景绘制调用均值10，总调用均值约36.17；最终成绩见上表。当前PCK为483348字节，原图和生成提示词保留在Git，PCK未包含原始大图、测试、截图和工作簿快照。

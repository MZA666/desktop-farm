# 桌面农场 0.8.6 商店卡顿修复验收

验收日期：2026-10-06。环境：Windows 11 x64、Intel Iris Xe、Godot 4.7.2。基于0.8.5（提交883810a），继续使用SAVE6/Layout6。

## 原因与修复

已复现种子商店打开后牧场和鱼塘运动停顿。旧版报价刷新受到动物移动及成长计时影响；53张作物卡片还反复恢复、校验和复制完整游戏状态，单次刷新占用共享主线程数秒，因而鱼塘动画也会停顿。

新版报价只跟踪与种子预算有关的状态；预览使用独立的精简状态，保留库存顺序、预留、返种和在途任务规则；避免重复预算计算，并将列表一次构建后挂回界面。搜索控件保留，实际购买、解锁和种植仍走原有交易与保存校验，保存失败仍回滚。

## 验收范围与兼容

全部检查使用隔离fixture，未读取或修改正式玩家存档，未停止用户运行的旧版程序。0.8.4/0.8.5的v6存档继续兼容。试玩时先正常退出旧版，再解压启动新版`DesktopFarm.exe`。

本轮调整控制器预览和预算计算开销；生产数值、地图布局、美术和原生DLL没有变更。旧版性能基线采用源码Debug执行，新版采用实际Release EXE；两次使用同一引擎、同一隔离状态和阶段时长，但执行类型不同，不能将差值全部归因于单项修改。没有重测长期CPU/内存或跨设备表现，不据此宣称游戏所有性能目标已经达标。

普通沙箱曾阻止烟测设置写入隔离测试存档，使紧凑模式烟测失败；允许隔离测试目录写入后，同一EXE的完整烟测通过。普通权限下部分引擎日志出现根证书读取或编辑器设置保存提示，离线功能检查通过；真实鼠标检查在可操作本测试窗口的权限下完成。最终验收引用成功复测记录，未将上述失败尝试计为通过。

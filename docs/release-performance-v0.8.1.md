# 桌面农场0.8.1正式程序性能报告

2026-10-03，Windows11 x64。完整原始证据见[evidence/performance-v0.8.1.json](evidence/performance-v0.8.1.json)。程序由官方release模板导出，正常主场景启动，对实际EXE的PID按1秒采样，2秒预热不计。未用源码引擎/外部--script替代正式程序。

满规模：96地块、96草点、84只动物（含全部11类）、9农夫、36鱼。CPU以进程CPU时间÷墙钟时间÷逻辑CPU数计整机容量，MB=1,000,000字节，采样期间正式玩家存档主档/.bak哈希保持一致。各模式独立连续60秒，原始EXE/PCK/DLL路径、SHA256和PID均记录在JSON。

目标CPU平均≤2%、峰值工作集≤200MB。仅鱼塘和收起CPU达标，全部模式内存未达标；最重牧场366.21MB。未降低画质、移除动物、强制清空工作集或以隐藏后的低用量冒充展开模式。省电能降低渲染频率，但满规模模型和原生窗口开销仍在。游戏时钟误差各模式约-0.003～-0.039秒，未因15帧、紧凑或收起而停产。

图集离线烘焙、最近邻渲染、背景按当前场景加载释放、静态景缓存与5Hz模型/插值已实现。仍需继续优化静态缓存失效、共享图集/字体和多个原生窗口的内存成本，最终达标前不将本版标为性能已达标。

追加300秒牧场运行因Windows锁屏导致开始/结束可见性不一致，严格采样器退出1，未把这段纳入上表；游戏有效时间仍推进300秒且保存成功。模型层另完成1800有效秒及中点重载一致验证。实际EXE30分钟持续可见运行尚未验收，不能将模型时长或本次300秒记录替代它。

上述为本设备、本次满规模测量，其他设备和DPI需再测。录像另使用正常EXE采集，录像CPU/内存不计入性能表。发布EXE/PCK/DLL在测试后保持不变，仅重新打包外部说明文档。

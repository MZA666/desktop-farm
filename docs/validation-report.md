## 构建与启动

工具链固定：Godot 4.7.2 stable（官方 `ed1daf0bf`）、Zig 0.16.0、Compatibility/OpenGL。Windows模板通过官方HTTPS按范围提取，ZIP CRC逐文件通过；未下载整个跨平台模板包，不宣称整个压缩包SHA256已验证。依赖与程序文件清单位于试玩目录 `manifest.json`。

当前试玩入口：`dist/DesktopFarm-v0.6.1/DesktopFarm.exe`。同目录 `.pck`、`desktop_native.dll` 和许可文本一起保留。源码、Python、Godot编辑器和原始文档都不是运行依赖。

实际独立程序已启动验证：工作目录为试玩目录，不传 `--path`，从同目录PCK加载；`DesktopFarm.exe`退出码0，三个场景和七个经营面板渲染成功，截图 `evidence/release-farm*.png`。测试存档使用 `user://test-data/`，未读写玩家正式主档。初版收起测试只确认了窗口可见性，截图检查发现子窗口停在上一帧。现已断开工具栏和菜单与主视口的渲染依赖，源码与实际Release复测均输出 `UI_COLLAPSED_MENU_OK`：主窗口隐藏时，工具栏仍可见，捕获结果页切换到设置页的图像缓冲确实改变，人工检查两套截图确认新页面可读。

源码图形版历史采样见 `performance-sample-v0.6.md`。真正独立Release程序已通过正常主场景入口完成五阶段短时采样，明细与包文件哈希见 `release-performance-v0.6.md`。采样使用实际渲染进程PID，以CPU时间除以墙钟时间及8个逻辑处理器得到整机容量百分比；内存阈值采用200,000,000字节。性能目标尚需优化，不以源码、无窗口逻辑或控制台包装器成绩代替发布程序实测。

最终版分离静态画面和动画绘制，并共享菜单/场景系统字体。农场30帧CPU由3.980%降至2.499%，牧场由4.038%降至3.462%；鱼塘为2.175%，省电15帧为1.640%，收起为1.437%。最终最大工作集276.09MB，峰值私有内存202.94MB。**省电和收起CPU达标，默认30帧三个场景及全部模式的工作集内存未达标。**优化后的独立EXE再次通过全部面板与收起刷新验证，20条控制器/输入断言通过；未改动生产模型及经济数值。

## 待长期/人工验收

以下尚未标记为通过：

- 用户电脑真实休眠/唤醒、休眠数小时、锁屏及强制关闭的完整组合。合成消息测试不能替代实际系统睡眠。
- 125%/150%缩放切换、多显示器负坐标、移除显示器与不同位置任务栏的所有组合。代码做逻辑/物理尺寸转换和可见范围修正；现有机器实际图形测试主要为1920×1080/100%。
- 三个场景分别连续30分钟、15 FPS连续30分钟、最小化连续30分钟的CPU/内存/漂移测试。短时采样另附报告，只作当前机的观测。
- 正式美术、完整音效、同场农夫路径与动作细节、安装包、发布签名和其他Windows硬件上的兼容测试。这些继续迭代，当前用占位人物及工作反馈验证玩法。

性能目标仍是系统整体容量口径平均CPU≤2%、峰值进程内存≤200MB；是否达到要看实际统计，不能由无窗口测试或控制台包装器进程的占用推断。主程序/渲染进程的真实PID需单独确认。

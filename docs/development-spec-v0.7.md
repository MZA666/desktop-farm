# 桌面农场开发规格 v0.7

日期：2026-10-01。交付为 Windows 11 x64 本地试玩 v0.7.0。继承 [v0.6 完整生产规格](development-spec-v0.6.md) 的全部经济、任务、存档与有效时间规则；本轮依据用户授权完善桌面体验、商店、性能及像素画面。

## 桌面体验

- Windows 通知区常驻托盘，支持显示/隐藏整款游戏、观赏/互动、种子商店、动物商店和退出；托盘双击显示或隐藏。
- 默认 Ctrl+Alt+F 切换整款游戏的显示/隐藏。快捷键冲突时提示注册失败，可继续使用托盘；退出释放本进程注册，不修改系统全局设置。
- 手动隐藏与「收起」独立：收起只隐藏场景，控制栏继续显示；手动隐藏包含控制栏和经营面板，本次会话优先于自动恢复。下次启动重新可见。
- 前台外部应用在游戏所在显示器真正全屏时，自动隐藏场景、控制栏及经营窗；普通带标题栏最大化不触发。离开全屏按此前状态恢复，不抢外部应用焦点，不永久置顶。
- 隐藏只暂停绘制，模拟和有效时钟继续；系统休眠与退出仍暂停，没有离线收益。
- 独立托盘消息窗口从不显示，防止重现启动空白框。经营窗仍按需生成内容后显示。

## 商店与图鉴

- 种子商店支持名称搜索、季节/机制和已解锁筛选，显示各品种图标、种价、库存、生产时间和售价。
- 选择区域作物前，使用独立模拟快照预览保护额和可投资额变化，复用既有命令校验；操作前检查不会修改玩家模型或写存档。
- 金币、首批补种预算、棚舍等级及容量不足等情况，按钮预先禁用并显示原因；待换种仍逐格生效，允许取消。
- 动物商店分为购买和现有动物，并按棚舍筛选、显示占用/容量；出售先确认标准价50%退款与已有待结算产物，再执行原有原子事务。
- 图鉴为分类、搜索、已发现筛选及图标网格，详情显示获取方式、累计登记和售价。75个真实产物都有来源；加工原料和成品区分登记与出售。
- 540逻辑像素宽的面板可阅读并操作，较长解释自动换行。
- 购种机制沿用库存优先、实际播种时自动购入；没有引入新的囤种、作物生长、动物退款或离线规则。

## 像素画面

- 暖木框、米色菜单、明亮草地、赭色耕土、蓝色鱼塘；最近邻采样和整数绘制位置。
- 四张原创AI生成图集：64个作物/野生植物/种包、11动物与3鱼/幼鸡/干草、16农夫动作帧、16产物/牧草物品。
- 共53作物、11动物和75产物都映射到实际图标。恐龙、鸵鸟、山羊等采用独立轮廓。
- 源PNG保留完整作者图集；构建时最近邻转换为32像素图集格，发布包只加载小图集并缓存AtlasTexture区域。场景、商店和图鉴共享纹理，避免启动时的大图解码、上传与回读。
- 生长期显示萌芽、中期及成熟外观；缺水、成熟、饥饿及待收产物标记保留。
- 人物在任务位置之间连续插值移动，并使用行走/浇水/收割动作帧；动画仅表现状态，不改变既定动作预算或保存格式。
- 参考用户提供的星露谷作物和动物页面及其可检索子页面。画风参考与实现记录见 [像素素材说明](art-direction-v0.7.md)；玩法数值继续来自已确认工作簿。

## 性能与验收

静态地面与说明在精确逻辑画面尺寸的 SubViewport 中栅格缓存，按有效秒、手动操作、悬停、分页和尺寸变化 UPDATE_ONCE；每帧主画面只提交缓存纹理与演员层，演员按30/15 FPS更新。共享中文系统字体，不重复设置字体名称触发额外载入。真正隐藏时停止缓存更新和动画/视口，恢复后重绘，保留生产和工具栏恢复能力。

牧场动画按阴影、共享图集动物、饥饿/产物标记分组提交，避免每只动物都在纯色与纹理指令间切换；图层排序保持状态标记可读。最终说明更新用 PackageOnly 重新打包已实测二进制，保留其SHA256身份。

验收包含13项配置核验、313项模型回归、控制器/商店事务、真实窗口和托盘/热键/全屏回归、源程序与Release图像检查，以及实际导出程序性能。目标仍为整机容量口径CPU平均≤2%、峰值进程工作集≤200MB。测量结果与未覆盖范围写入独立v0.7验收记录；历史v0.6数字不作为新版本成绩。

保留v1玩家存档，设置和经济状态均可沿用。测试使用 --benchmark-fixture 与独立单实例命名空间及测试目录；并行试玩时不关闭玩家进程，不将玩家正常自动保存误判为测试写入。

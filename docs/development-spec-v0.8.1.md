# 桌面农场0.8.1开发规格

2026-10-03。本规格对应用户确认的[完整开发规划](development-plan-v0.8.1.md)。基于Godot4.7.2与C/Win32桌面窗口层，交付Windows11 x64本地试玩。经济基础仍来自production.json及原数值表；玩法配置gameplay-v0.8.json已更新版本及鱼塘升级档。

## 场景、坐标与输入

农场1536×512、牧场1920×512、鱼塘1536×512为三个独立世界。默认窗口总高420，场景约352；紧凑总高240、场景约172；收起约32。DPI和短工作区只夹紧可见窗口，切换显示方式、分页和镜头不改变世界坐标或计时。

world_layout.gd统一96地块（16列×6行、56像素土面）、96个不规则草锚点、7类棚舍入口、食槽、仓库、码头与障碍/路线。illustrated_view.gd用新场景背景及独立透明精灵渲染；静态景物缓存，演员按脚底排序。图集按最近邻离线烘焙，共享小图集及单个当前场景背景缓存。小动物四方向5/5/5/4个原始帧，运行时左向第五帧循环首帧；牛、山羊、羊、猪独立4×4步态图集。幼年/进食各有独立图集。

种植仍按稳定地块ID管理偏好、预留和农夫已领用种子，保持整库耗尽才默认订购。地块选中/框选/Shift选择、观察穿透、地图滚轮上下、Shift滚轮横向、中键上下拖动继续使用。鱼命中跟随绘制游动位置；动物命中按实际模型插值后的身体，逆深度只命中一个实例。

## 动物、牧草与农夫

game_state.gd使用0.2秒固定步骤，ranch_life.gd处理独立可保存随机流、坐标、朝向、行为、路径、整餐预约、进食与互动。动物小型12、大型10像素/秒；正常走停、觅食与饥饿移动继续，不再绑定棚位。低频5秒食物决策依据真实可达路线、餐量和距离提前出发，计入走远与决策间隔、进食的时间余量。软避让使用24像素空间索引。遇到非法目标/超时释放预约。

每300秒一餐：小动物2簇草、大动物4簇；不足整餐则预约1份食槽干草。动物依次到达所有草点后，完成2秒进食动作并在餐间隔到期时统一扣整餐。普通草保根，两母草保护；割草任务与动物预约共享账本，不能重复消费、远程消费或扣半餐。牧草180秒快照生长/邻近扩散，保存固定位置和外观。

农夫速度16～48、默认32，沿真实路线到达后动作2秒。收取目标保存动物实例ID，行走中定期追踪；到达附近动物短暂配合收取，随后恢复活动。无效/超时任务取消释放资源。

互动每只120秒奖励冷却，全局2秒输入间隔；幼年单次≤30秒、全期≤20%，成年单次≤标准周期5%、每轮≤10%。饥饿、待收、观察模式不奖励。成年/收取不重置奖励冷却，幼年奖励不溢出至成年；下一轮重置成年本轮额度。实际奖励、冷却、周期序号入存档，显示轻量爱心和短提示。

## 鱼塘结算与升级

pond_rules.gd为纯经济命令模块，使用product_id检查图鉴。首次未收录鱼消耗并登记、不加金币；已收录直接出售，不修改图鉴记录；无捕获确认窗口。一次成功命令同时移鱼、金币/图鉴、待处理状态和冷却。main.gd立即原子保存，失败restore(before)整体回滚并提供重试。

网20/15/10/5秒，逐档费用200/400/800；容量12/18/24/36，逐档300/600/1800。保护补种预算后方可扣款；升级不重置当前网冷却/补鱼倒计时、不赠鱼。仍180秒补一条、空网也冷却、一次最多一条、三鱼种原售价/概率保留。

v1/v2旧档的pending_fish在严格加载和迁移保存成功后，以显式resolve_pending_fish命令按同样规则结算并保存。restore本身不隐式加钱/登记，保存失败仍可还原旧待处理鱼；当前冷却与补鱼计时保留。恢复保存再重试只结算一次。

## 存档与发布

存档版本3。严格校验坐标、合法路线、食物预约账本、互动额度、鱼升级档及任务；v1先迁移v2再v3。旧版本原档复制为不可覆盖version-v1/v2备份，内存迁移验证后原子替换；失败保留原档并阻止启动。保留金币、库存、稳定地块/动物ID、产物/成长、食物、图鉴及随机流。农夫动作保留余时，行走目标按稳定ID映射并保留已领用资源。退出与休眠不补离线收益。

窗口普通Z序、托盘、快捷键、全屏避让、无空白经营窗及隐藏继续生产沿用原生层。正式发布用官方release模板，EXE/PCK/DLL便携交付；测试与录制入口均需隔离夹具参数，使用独立测试存档，不能关闭玩家程序。

自动回归、实际EXE截图/60秒录像和性能数据见[验收记录](validation-v0.8.1.md)及[性能报告](release-performance-v0.8.1.md)。完整多显示器与真实系统休眠仍按明确未测项目记录，不能把模型测试当实机结论。

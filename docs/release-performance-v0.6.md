# v0.6 Release EXE 短时性能实测

版本说明：本文对应用户反馈前的v0.6被测包及其明确列出的哈希。v0.6.1已另行修复窗口和入口，功能验证见 `hotfix-v0.6.1.md`；尚未重跑五阶段性能，不能将本文数字当作v0.6.1的新实测。

2026-10-01在真实Windows 11设备上完成两轮独立Release采样，所有阶段退出0。最终交付版采用静态/动画CanvasItem分层及共享系统字体。**优化后省电与收起模式CPU低于2%；30帧的三个场景CPU及所有模式的工作集峰值仍未达到2%/200MB目标。**短时样本不代替每模式30分钟的正式性能验收。

## 测试对象与口径

- Godot 4.7.2 stable official，提交 `ed1daf0bf001b61586d9930840f2f1394092c079`；使用官方 Windows release 模板。
- Windows 11 专业版 10.0.26100，Intel Core i7-1165G7 @ 2.80 GHz（4 核 / 8 逻辑处理器），系统可见内存 16,805,044,224 字节。
- Intel Iris Xe Graphics，驱动 31.0.101.5186，OpenGL 3.3 Compatibility；1920×1080，DPI scale=1.0，场景窗口 1920×240。
- 每次独立启动满规模夹具：96 耕地、96 草格、84 成年基础动物、9 农夫、12 条鱼；观察模式开启鼠标穿透，工具栏仍可交互。
- **正常应用入口，无 `--path`、无 `--script`。** 五次运行均报告 `editor_feature=false`、`debug_feature=false`，加载 `res://scenes/main.tscn` 的打包资源；实际 EXE 路径及 PID 与外部采样对象一致。
- 每阶段预热 2 秒，再测量约 24 秒。每秒采集真实进程 CPU 时间、WorkingSet 和 PrivateMemory；只计入连续处于测量区间的样本，各有 23 个样本、23.31–23.41 秒。五次启动总计 138.57 秒。
- CPU 为 `进程 CPU 秒增量 / 对应墙钟秒数 / 8 × 100%`，表示占整机逻辑 CPU 容量的百分比。内存统一使用 **MB=1,000,000 字节**，没有将 200 MiB 当作 200 MB；峰值指每秒样本中的最大值，可能漏掉更短暂的峰值。

复现命令：

```powershell
& 'D:\game\tests\benchmark_release.ps1'
```

采样器对普通 EXE 传入 `--benchmark-fixture --benchmark-scene=... --benchmark-seconds=24 --benchmark-output=绝对目录`；省电及收起阶段分别追加 `--benchmark-power`、`--benchmark-collapsed`。只有夹具模式且指定时长才激活自动测量与退出，不改变正常试玩流程。

## 收起、时间和存档

| 模式 | 平均主场景 Canvas draw calls | 平均工具栏 draw calls | 平均全局 draw calls |
| --- | ---: | ---: | ---: |
| 农场 30 FPS | 214.26 | 20 | 235.26 |
| 牧场 30 FPS | 188 | 20 | 209 |
| 鱼塘 30 FPS | 32 | 20 | 53 |
| 农场省电 15 FPS | 214.26 | 20 | 235.26 |
| 收起 30 FPS | **0** | **20** | **20** |

收起阶段开始和结束均验证：主场景 HWND 隐藏、工具栏 HWND 可见、场景动画处理停止。根 viewport 不绘制时，独立工具栏仍持续绘制；这与此前子窗口随根 viewport 冻结的无效旧样本不同。正式 GUI smoke 另有收起后设置面板实际像素更新验证，见 `validation-report.md`。

五阶段各推进 24 个有效游戏秒，墙钟为 24.024–24.060 秒，差值约 -0.024～-0.060 秒，符合按秒提交并保留余时的机制。收起阶段的游戏逻辑继续运行。

全部夹具存档只写入 `C:\Users\Administrator\AppData\Roaming\Godot\app_userdata\桌面农场\test-data\benchmark-save.json`，每次保存成功。正式主存档及 `.bak` 在测试前均不存在，结束后仍不存在；测试没有读取、创建或改写玩家存档。

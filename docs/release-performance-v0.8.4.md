# 桌面农场 0.8.4 正式程序性能报告

2026-10-06，Windows 11 26100、Intel Iris Xe、8逻辑CPU。使用最终导出的 `DesktopFarm.exe`，六模式顺序运行，每模式30秒，另有2秒预热。逐秒按该测试进程PID采样，仅统计测量阶段内的完整区间，每模式29个样本、约29.4–29.6秒。CPU=进程CPU增量÷墙钟增量÷逻辑CPU数×100%，MB=1,000,000字节。

每次均重新创建隔离满规模夹具：100耕地、96草点、84动物、9农夫、36鱼，以及252份产物、20个固定地面合堆。这些资产只用于测试，不改变正常开局的24块地。所有六模式的正式运行身份、原生模块、PID、实际窗口可见状态、隔离存档和生产时钟验证均通过。

初始目标为平均CPU≤2%、峰值工作集≤200MB；本次六模式均未达到这两项目标。功能已通过验收，满规模资源占用仍需后续优化。省电模式的模拟时钟继续运行；收起模式的FPS是主循环频率，场景动画已停止处理。

本轮缓存优化通过实际绘制计数验证：生长阶段不重烘焙未改变的土地，鱼移动和普通时钟不重烘焙鱼塘，牧场仅在草量或库存等画面内容改变时更新。不能因此宣称总体CPU已经降低。0.8.2样本在不同日期、96块地规模下测量，不能作为严格同环境对照，也不能把本报告当作30分钟持续运行或多设备验收。

六模式有效时钟与墙钟差为-0.0597～-0.0092秒，保存成功；没有因省电、紧凑或收起停止生产。测量总墙钟约203.4秒。没有读取、改写或停止玩家正式存档及既有试玩进程。

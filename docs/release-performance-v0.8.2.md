# 桌面农场0.8.2正式程序性能报告

2026-10-03，Windows 11 26100、Intel Iris Xe、8逻辑CPU。本报告使用正式导出 `DesktopFarm.exe`，顺序启动六个独立测试实例，每模式30秒，2秒预热排除；按实际EXE PID逐秒采样，只统计完全位于测量阶段的约29.4秒区间。CPU=进程CPU增量÷墙钟增量÷逻辑CPU数×100%，MB=1,000,000字节。

满规模96地块、96草点、84动物、9农夫、36鱼；另预置每只动物3份产物，共252份、20个固定合堆，覆盖新增地面物品的绘制和库存。预置仅用于测试，不改变正式新游戏规则。三场景、15帧、紧凑和收起生产时钟均继续，保存成功。

| 模式 | 平均CPU整机% | 峰值工作集MB | 实际FPS |
| --- | ---: | ---: | ---: |
| 农场展开30帧 | 2.596 | 333.83 | 30.03 |
| 牧场展开30帧 | 4.050 | 385.51 | 30.01 |
| 鱼塘展开30帧 | 2.366 | 350.32 | 30.00 |
| 农场省电15帧 | 2.108 | 333.04 | 15.01 |
| 农场紧凑30帧 | 2.927 | 338.35 | 29.99 |
| 收起工具栏30帧 | 1.722 | 321.16 | 29.98 |

既定目标平均CPU≤2%、峰值工作集≤200MB。只有收起CPU达标，内存全部未达标；本版不声称性能目标已完成。最重牧场需继续优化动物/物品提交、路径计算、背景缓存与字体/图集内存。未降低画质、移除动物或强制清空工作集。

游戏有效时钟与墙钟差为-0.0026～-0.0484秒，未因省电、紧凑或收起停产。测试核验正式模板、PCK主场景、非编辑器/非debug、原生模块、实际HWND可见性与渲染处理状态；测试实例使用PID独立原生命名空间和 `user://test-data/benchmark-save.json`。不枚举、读取、写入或停止玩家存档/旧试玩进程。旧试玩可以自行继续运行；本次数据是该桌面环境中的实际测量。

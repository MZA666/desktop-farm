# 桌面农场 0.8.3 开发规格

日期：2026-10-04。基线：0.8.2，提交 `d869f9c`。本轮落实用户试玩反馈：牧场干草不清楚、农田尺寸与排布不贴合背景、上下箭头切换太粗。生产、价格和扩建数量继续沿用原数值。

## 干草库存

牧场左下角固定显示两行「草仓 当前/容量」「食槽 当前/容量」，分别配图标和实际库存比例条。横向切页、垂直移动镜头、展开或紧凑显示时，面板始终位于视口内。容量读取当前储粮等级配置，四档各24、64、128、256。

显示模型的物理库存，不把动物预约的一餐当成已经食用，也不把农夫搬运的预约算成已经转移。草仓与食槽之间仍由农夫完成任务后转移，动物吃完一餐后扣食槽库存。鼠标停留显示用途说明，点击库存面板不会误点其后方的动物或畜栏。世界中的实体食槽按库存比例填充。

## 农田几何

沿用原1536×512背景和独立人工标注的泥土多边形，背景SHA256仍为 `9983249ac55df7956fd875aeed08d2ab31bd81734b8562e301dd170f1db53fe8`。不扩大泥土范围，地块矩形及2像素安全余量必须全部在边界内。

每格由48×36改成54×40，步距56×42。六行按土地轮廓排布，格数为15、16、18、18、16、13，总计96。

有效种植矩形总面积207,360平方像素，比旧165,888增加25%。覆盖原保守泥土多边形约79.24%，其余为不规则边角和格间留白。初始24格为第一行15格及第二行前9格；扩建继续按原global_index开启后续格，原地块ID、价格、种植偏好和作物状态不变。ID名称中的旧行列编号不作为新视觉布局。

`World.plot_rect` 统一土壤覆盖、框选、点击区域；农夫工作点为地块左上+(27,37)，作物根锚为+(27,36)。作物画面缩至52×78，土垄按实际格高分布。拖框仍按土地矩形；普通单击与悬停优先命中最上层作物的不透明像素，再回退到土格，避免高株叶片覆盖上一排时选错地块。

## 镜头操作

旧步长 `max(56, view_height*0.55)` 在展开时约193.6，而全部纵向范围只有160，导致一次直接到边。新箭头固定32逻辑像素，滚轮每格16像素并保留高精度滚轮系数。Shift+滚轮继续横向切页，中键拖动继续平移。

新增「居中」按钮；初次进入三个场景均使用世界中心。世界高512，展开视口352时居中偏移80，紧凑172时偏移170。上下极限严格夹紧到世界，不露空白。

各场景在本次运行中独立记忆希望观察的世界中心。改变显示高度时只调整视口，不把暂时被夹紧后的中心覆盖回记忆。例如紧凑最底340→展开夹紧160→回紧凑恢复340。主动移动、拖动或聚焦地块才更新观察中心。镜头状态不写入经营存档，不改变金币、生产进度或实体世界坐标。窄到640逻辑像素时仍保留全部镜头按钮及显示模式按钮。

## 存档版本与迁移

SAVE_VERSION及LAYOUT_VERSION升为5。旧几何完整冻结在 `world_layout_v4.gd`，v3文件也保持。v4档先按冻结布局严格验证路径、目的地与地块绑定，验证成功后才迁到新布局；不能通过重寻路掩盖损坏路径。

96个地块经营字段逐值保留。农场正在行走的农夫保留可通行的世界位置，重算去新工作点的路线和所需行走时间；已到达动作阶段的农夫移动到新工作点，保留剩余动作时间、已用体力及任务预约种子。牧场、鱼塘、动物食物预约、固定产物堆、领取认领和图鉴保持。

v1/v2/v3按各自冻结规则验证并迁到冻结v4，再进入v5。第一次正式迁移创建不可覆盖的原版本备份，校验原文件字节SHA；写入失败停止启动并保留原档。未来版本拒绝覆盖。回退必须退出所有游戏并使用对应原版备份。所有本轮测试使用隔离fixture，不读取、迁移或停止玩家旧试玩。

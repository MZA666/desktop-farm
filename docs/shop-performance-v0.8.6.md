# 0.8.6 商店响应性能报告

2026-10-06，Windows 11 x64。满规模场景中，0.8.5源码版打开种子商店后出现约4.7秒的自然帧回调停顿；0.8.6实际导出EXE的对应最大间隔为牧场90.342毫秒、鱼塘70.526毫秒。新版四个短时阶段均未出现超过100毫秒或200毫秒的自然回调间隔，场景中的84只动物和36条鱼在模型坐标与画面坐标上均继续移动。本报告验证商店响应，不代表整款游戏的长期CPU、内存或所有性能目标已经达标。

原始记录为[0.8.5源码基线](evidence/shop-performance-v085-baseline.json)和[0.8.6导出EXE结果](evidence/shop-performance-v086-release.json)。旧版测量通过34项记录及功能检查；新版通过61项记录、功能与指定性能阈值检查，两份记录的`failures`均为空。

两次使用同一台机器、Intel Iris Xe Graphics、Godot 4.7.2 stable官方构建（`ed1daf0bf001b61586d9930840f2f1394092c079`）及30帧/秒上限。每个阶段恢复相同的隔离SAVE6/Layout6测试状态：100块地、84只动物、36条鱼、9名农夫、53种作物。牧场和鱼塘各测商店关闭、种子商店打开两个阶段，每阶段自然运行8秒；商店打开阶段确实渲染全部53张作物卡片。

执行方式存在区别：旧版由Godot引擎读取0.8.5源码运行，记录`debug_feature=true`、`editor_feature=true`；新版由`dist/DesktopFarm-v0.8.6/DesktopFarm.exe`及随包资源通过正常应用入口运行，记录两项均为`false`。表格反映这两次执行的实测结果，不能把差值或比例全部归因于某一项代码修改，也不是相同发布模式下的纯变量对照。

新版全部四阶段合计960个自然样本；其中没有超过100毫秒或200毫秒的间隔。打开面板本身为218.291/183.904毫秒，属于另行测量的操作，不能算作“所有操作都低于100毫秒”。新版两次打开均低于本次250毫秒阈值，六次强制刷新及六次报价刷新均低于100毫秒；四阶段P95均低于70毫秒阈值。JSON还记录了相对旧基线的刷新比较，该比较仍受源码Debug与导出Release执行方式差异影响。

新版牧场的两个阶段均有84只动物的模型及画面坐标发生变化，鱼塘的两个阶段均有36条鱼发生变化。商店打开阶段的动画时钟分别推进7.965秒和7.970秒，墙钟分别为8.017秒和8.002秒；旧源码版对应动画时钟仅推进3.322秒和3.370秒。这里同时检查实际模型位置与渲染插值位置，避免只以生产计时继续推进来判断画面是否活动；这仍是8秒窗口内的检查，不能保证更长运行中永无停顿。

代码检查确认并修复了三个相互叠加的开销来源：

1. 每张作物卡片的购买、默认种子及种植预算预览原先反复恢复并校验完整存档。新版从已经校验的运行模型取快照，在独立预览状态上计算，不为每个卡片再次执行完整`restore`。
2. 商店报价的刷新条件原先受到动物移动及成长计时影响；这种报价计算占用共享主线程，也会阻塞鱼塘动画。新版种子商店及种子库只跟踪相关预算输入，包括金币、地块种植状态、预留及在途种子、库存、默认品种、解锁、选中地块、购买数量和保存阻断状态；无关的角色移动不再使种子报价失效。
3. 逐卡片预览原先还复制动物路线、鱼、牧草、图鉴等无关状态。新版种子相关预览只复制预算分配实际需要的地块、任务和库存字段，保留种子分配顺序与领用语义。

正式购买、解锁、种植及升级仍经过原有命令校验和原子保存；写入失败仍回滚。旧预览路径与新路径完成548次预算等价比较，覆盖53种作物、金币充足/不足、已付费/预留/返种种子及非法参数，检查结果、提示、保护额、可投资额和运行状态不被预览修改。相关回归共通过1443项断言：控制器事务及面板766项、模拟与持久化440项、种子预算/库存/领用/布局/迁移237项；548次比较包含在控制器766项内，不重复累计。完整交付验收见[0.8.6验收记录](validation-v0.8.6.md)。

测量使用真实图形窗口及实际主场景，由独立测试实例加载隔离测试状态。JSON记录`player_save_accessed=false`、`save_written=false`；正式玩家存档未读取或写入。测试期间保留已运行的旧版玩家进程，未停止或操作它，其他后台负载没有排除。默认权限运行时Godot日志出现根证书库读取提示；本次测量不使用网络，该提示未阻止上述功能与性能检查通过。

本轮没有长时间CPU、内存或跨设备测量，没有覆盖所有屏幕分辨率和持续经营状态。整款游戏资源占用仍以[0.8.4历史性能报告](release-performance-v0.8.4.md)为参考，不把这次短阶段商店结果替代总资源验收。生产、地块、派工及渔网规则沿用[0.8.4开发规格](development-spec-v0.8.4.md)，v6存档继续兼容0.8.4和0.8.5。

## 实际发布性能

实测设备：Windows 11专业版26100，i7-1165G7（4核8逻辑线程）、Intel Iris Xe 31.0.101.5186、16GB内存、1920×1080 / 100% DPI。每阶段正常EXE入口，隔离满规模夹具96耕地、96草格、84动物、9农夫、12鱼，预热2秒后逐秒采样。CPU为进程CPU秒 / 墙钟 / 8逻辑线程 ×100%；MB=1,000,000字节，峰值保留自然释放之前的有效测量样本。

初次大图运行时转换版本的30秒五阶段样本CPU为0.830%～1.617%，峰值工作集最大290.10MB；随后改为离线转换，PCK由5253576字节降至480136字节，仅加载256×256及3张128×128小图集。15秒比较样本农场峰值工作集253.55MB、收起250.49MB，内存下降但未达200MB目标；短测农场CPU2.082%不作为最终60秒五阶段结论。

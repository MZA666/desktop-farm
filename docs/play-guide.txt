桌面农场 0.8.0 · 阶段A · Windows 11 本地试玩

启动：双击 DesktopFarm.exe。请保留同目录的 DesktopFarm.pck 与 DLL，移动时一起移动整个文件夹。首次启动贴屏幕底部、位于任务栏上方。

【控制栏】
农场 / 牧场 / 鱼塘：切换画面，其他场景继续生产。
种子商店：搜索、筛选作物，按1/5/10/25或自定义数量购买入库，选择默认自动订购品种。
种子库：查看可用、预留和在途种子；选择品种后，在农田点击、框选或按Shift多选地块，再点击“种植所选”。也可先选地再从库中安排种植。
动物商店：按棚舍购买或查看现有动物，等级、容量和资金不够时显示原因；出售需确认退款与待结算产物。
经营：商店、建设扩展、农夫管理、收藏图鉴、设置。
窄屏时若商店或种子库快捷按钮未显示，请通过经营首页打开，托盘也能打开两个商店。
≡：按住可上下拖动农场位置，松开后保存。
‹ / ›：窄屏时翻页。
可交互 / 观察中：切换场景输入。观察时可点击下方桌面，控制栏仍可用。
收起：只隐藏场景，生产继续。再次点击展开。
退出：保存后结束进程；下次启动不补离线收益。
游戏不永久置顶。点击其他应用后，该应用会显示在游戏前方，游戏仍继续生产；经营窗只在点击入口时显示。
托盘：通知区的小图标可显示/隐藏整款游戏、切换观赏/互动、打开商店及退出；双击也可显示/隐藏。
Ctrl+Alt+F：显示/隐藏整款游戏（包含控制栏），与“收起”独立。热键冲突时请使用托盘，下次启动重新可见。
外部全屏应用位于同一显示器时自动隐藏，离开全屏后按此前状态恢复；手动隐藏时不会自动弹回。隐藏期间生产继续。

【开局】
1000金币、24份防风草种子、24格耕地、4只幼鸡、6格牧草、8份干草、3个农夫、12条鱼。
初始补种保护额480，可用金币520。保护额只是预留，不是已扣款。换种和扩建也会增加需要保护的种子预算。

【种植】
农夫自动播种、浇水和收获。可交互时可点击缺水地块浇水。成长需先浇水；成熟后最多等待1份，不腐烂。收获后自动登记图鉴并出售。
每块地独立种植，初始24块、最多96块。新农场没有6区域限制，经营→建设扩展每次开垦一块；旧存档原有开地保留。农田的荒地、树木、溪流和小桥用于表现自然景色。
购买种子时扣金币入库。设置种植安排时，空地等待农夫播种，已有作物等本轮收获/加工结束才切换，不重置成长进度。部分品种需先解锁。在种子库选择地块后可取消未生效的安排，预留种子返库，已经买到的种子不退成金币。
每次播种先用本格专用返种/预留，再用地块偏好品种库存；缺货时按种子库固定品种顺序用其他可用种子。只有整个可用种子库为空，才购买1枚默认种子用于本次播种（初始防风草）。已经预留或领用的种子不能被另一块地重复使用。单格偏好仍保留，新买到相应种子后优先使用。
界面显示“可用”是普通库存，“预留”是绑定待换种地块的种子，“在途”是农夫已经领用但尚未播下的种子。补种保护额只是未来金币缺口预留，种子购买、换种、默认订购和扩建均会重新计算。

【养殖】
动物自动吃草；不足一整餐时吃食槽干草。饥饿暂停成长和生产，没有死亡。农夫自动割普通满草、添草和收产物。母草永远保留，普通草保留根。
经营→建设扩展可开草地、买草种、升级储粮和棚舍。动物商店可购买或出售动物；退款为品种标准购入价50%，赠送动物也退款。

【捕鱼】
鱼塘在可交互模式下点击鱼，或短拖经过鱼后松开。一次最多1条，渔网冷却20秒，空网同样冷却。捕获后选择出售拿金币，或消耗该鱼登记图鉴。关闭结果窗口可稍后处理，再次进入鱼塘会显示待处理鱼。
池塘最多12条鱼，每3分钟自然补1条；鱼塘不会自动产生金币。

【农夫】
每个场景最多3人；本岗无事且满精力时自动支援。经营→农夫管理可招聘和免费转岗。转岗需等待工作完成、回到本岗。
设置→农夫行走速度可调16～48像素/秒，默认32，步长4。农夫按真实距离走到作业点，再完成2秒动作；调慢会降低远处任务效率，翻页和窗口缩放不改变世界距离。

【收藏图鉴】
经营→图鉴可按作物、动物产物、鱼分类，搜索或只看已发现；点击图标查看获取方式、售价和登记数量。

【存档与时间】
每30秒自动保存，经营操作立即保存。最小化、收起、锁屏继续；退出、关机、休眠暂停。没有离线收益。
存档保存在当前 Windows 用户目录，设置→打开存档目录可查看。写入失败会提示并撤回经营操作；检查权限后点重试保存。损坏文件请保留主档和.bak备份。
首次打开旧版存档会保留独立的 version-v1 备份后升级为v2；金币、作物、任务领用、生产进度和图鉴继续使用。请先退出旧版程序再启动新版。升级写入失败会保留原档并停止启动，未知新版存档不会被旧备份覆盖。

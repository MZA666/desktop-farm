# v0.8.2 原创边景与农夫动画素材

2026-10-03，使用 Codex 内置 image_gen 生成及修改；不引用游戏发行包中的美术文件。三场景主体继续采用 v0.8.1 的独立原创背景。

## 生成约束摘要

- `source/woodland.png`：宽幅像素田园边景，林木、草坪、野花、岩石和自然土路；与既有场景的俯视角度、日光、色板及像素簇细节一致。无房屋、鸡舍、围栏、人物、动物、文字，左右不使用重复瓦片。
- `source/pond-margins.png`：独立宽幅河岸与水面边景，左侧树林、草地与缓弯岸线，右侧延伸清澈蓝绿水面、少量芦苇及石岸；无码头、船、人物、鱼或文字。游戏只取其中右半部分延续池塘右侧，左侧使用独立林地边景。
- `source/farmer-walk.png`：草帽、蓝衣、棕靴的原创农夫，透明 alpha，四行依次向下、向右、向上、向左，每行四个完整全身动作。前后接触帧明确交换左右腿，双腿与双靴可辨；身体、衣服、帽子及尺寸保持一致，无遮挡、无地面、无文字，帧间留透明间隔。
- `source/farmer-second-draft.png`：透明农夫动作页，其中最后一行八帧从站立、弯腰、伸手到拾取恢复站立，作为地面产物的拾取动作来源；其他行不导入正式运行图集。

步行动作经过多轮检查与重新生成。早期草稿和参考图保留在 source 便于追溯，但不导入正式图集，也不随试玩包导出。

## 烘焙与使用

`scripts/bake_scene_assets_v082.gd` 使用 Godot 对原图作离线分帧、统一缩放和脚底对齐。PNG 原始图不修改。运行素材使用最近邻采样，RGBA 透明边界，农夫帧为64×80，脚点为(32,78)。

正式步行原图每方向有四个动作，运行图集每方向八个相位。向下、向右、向左按原图列顺序 `[0,0,1,1,2,2,3,3]`；向上经原图检查后按接触姿态顺序 `[0,2,1,3]` 排列，运行映射为 `[0,0,2,2,1,1,3,3]`，使第0与第4相位采用原图中左右靴交替的实际姿态。每个原动作保持两相位，未生成额外中间动作、未镜像腿，也不修改原始PNG。向上站立使用第6相位，其余方向使用第2相位。manifest按方向记录实际源列映射，不能用重复帧伪称八个独立姿态。拾取保留八个不同动作。

步行相位由实际世界移动距离驱动，每3像素前进一个相位，一轮24像素；调节速度会相应调整步频，移动镜头不增加步行距离。暂停、闲置时使用站立帧，到达固定产物后播放拾取动作。

`runtime/manifest.json` 记录源图 SHA256、帧边界、脚点、统一缩放比例、原帧映射和导出文件。`runtime`只含最终两张边景和两张透明农夫图集。
